## Priority uncovered work

1. **#103: integrate and validate the small existing PR #104**, rather than recreate it. `src/prompt-symbol-registry.js` still has three case-sensitive `gpt-` expressions; PR head `d6f417b` changes those expressions and adds footer/modal tests.
2. **#67: reproduce and fix the wrapped-prompt spinner trigger.** `session-state.js` still uses `/[|/\-\\]\s/`, splits only CRLF/LF, and prevents ordinary quiet settling from `thinking`. The older PR #84 also retains the trigger. This is an uncovered deterministic state-machine defect suitable for a bounded pure regression; changing thinking semantics more broadly requires care with #60.
3. **#99: HTTP cross-host shared-reference transfer is missing.** SSH uses `ensureRemoteSharedReference` / `remoteEnsureSharedContext`; HTTP targets fall through to `ensureLocalSharedReference` before posting to the remote daemon. A pointer can therefore still name a file present only on the sender. Add bounded authenticated transfer or fail closed before delivery; do not count the SSH implementation as covering HTTP.
4. **#100/#111: missing host-qualified return identity and daemon-side exact forwarding.** `lastInjectFrom` / `lastInjectReplyTo` still store body values, and reply resolves them through the ordinary target resolver. Existing PR125 exact-local targeting is useful but does not implement remote daemon forwarding or authenticated remote sender identity.
5. **#121: fix the test's idle-port ownership assertion.** `test/daemon-lifecycle-55.test.js` still checks that a previously free port remains empty; it does not prove a listener was created by this invocation. Source supports the race hypothesis, not a proven production defect.
6. **#101, #92, #78, #96, #102, #106** are real missing capabilities, with broader contracts than a one-line fix. Keep the policy boundary for #97/#113/#132–134 explicit. Reuse PR112 for service work and PR84 for its reviewed scoped admission/VT work rather than silently replacing them.
